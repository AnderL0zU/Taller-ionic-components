⚖️ De Nativo a Multiplataforma

¿Por qué comenzamos con Android Studio y Kotlin en las unidades previas y por qué pasamos a Ionic ahora?

Criterio Desarrollo Nativo (Android Studio) Desarrollo Híbrido (Ionic + Angular)
Lenguajes de Programación Kotlin / Java + XML o Jetpack Compose TypeScript + HTML5 + SCSS
Bases de Código (Codebase) Separadas: Una para Android y otra para iOS (Swift) Un solo código base para Android, iOS y Web (PWA)
Motor de Renderizado Widgets y Canvas nativos del sistema operativo WebView nativo optimizado con componentes Web UI
Velocidad de Compilación / Pruebas Lenta (Gradle build, emulador pesado en RAM) Ultrarrápida (Hot Reload instantáneo en navegador)
Acceso a Sensores y Hardware Directo mediante los SDKs oficiales de Google / Apple A través de plugins puente (Capacitor Plugins)
Curva de Aprendizaje Alta (Específica para cada plataforma) Baja a moderada para quienes conocen desarrollo web

¿Cómo funciona el concepto de WebView?

En una aplicación Ionic, tu interfaz corre dentro de un WebView nativo (un contenedor de navegador sin barra de direcciones). Cuando la app necesita usar hardware (Cámara, GPS, Bluetooth), utiliza Capacitor como un puente bidireccional que traduce llamadas JavaScript a código nativo de Java/Kotlin o Swift.

1. Capa de Aplicación Web

Componentes de Ionic (ion-button, ion-card), Angular y TypeScript.

2. Puente Capacitor (Bridge)

Traduce las promesas de TypeScript a llamadas nativas del sistema operativo.

3. Hardware & Sistema Operativo

Sensores, Cámara, Geolocalización, Batería, Sistema de Archivos.

📂 Anatomía de un Proyecto Ionic

Explora la función de cada archivo dentro del componente y comprende cómo interactúan entre sí.

Árbol de Archivos (src/app/home/)

💡 Regla de oro en Ionic:

La lógica NUNCA va en el HTML ni en el SCSS. La lógica de negocio, cálculos y consumo de APIs pertenecen exclusivamente a la clase en .ts.

home.page.ts

Lógica del componente y manejo de estado

// TypeScript Component Logic
export class HomePage {
  // Strongly-typed state variables
  public studentName: string = 'Carlos Mendoza';
  public counter: number = 0;
  public isServiceActive: boolean = true;

  // Methods connected via Event Binding (click)
  public incrementCounter(): void {
    this.counter++;
  }

  public toggleServiceStatus(): void {
    this.isServiceActive = !this.isServiceActive;
  }
}
Explicación Didáctica: Aquí se define el tipado estático con TypeScript. Las propiedades públicas (`studentName`, `counter`) están disponibles automáticamente en la vista sin necesidad de llamadas DOM manuales como document.getElementById.

1. Interpolación: Al escribir en el input o interactuar con los botones, Angular actualiza la variable de clase y repinta el DOM instantáneamente.
